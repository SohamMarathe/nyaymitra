# Demo Conversations

Empty on purpose for now. Once you have Phase 1 running end-to-end, run a
handful of real conversations through the actual system (not fabricated
ones) and paste the real input/output pairs here — one file per language,
e.g. `consumer-complaint-en.md`, `labour-dispute-hi.md`,
`cyber-fraud-mr.md`.

Real transcripts are much more convincing in a portfolio than polished
fake ones — and they double as a regression check: re-run the same query
after a change and see if the answer got better or worse.
